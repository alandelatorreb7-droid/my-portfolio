BuildRight — Construction Cost Estimator
React Node.js PostgreSQL Deployed on Railway
Jan 2026 — Present

Overview

A full stack web application that helps El Paso, TX contractors build professional construction cost estimates in minutes. Built and deployed solo from scratch.

The Problem It Solves

Most small contractors in El Paso rely on spreadsheets or pen and paper to estimate project costs — a slow and error-prone process. BuildRight reduces a 30–60 minute task to under 10 minutes with locally researched prices, automatic calculations, and a professional PDF output ready to hand directly to a client.

Key Features

  • 280+ locally researched El Paso material and labor prices
  • Professional PDF quote generator with company branding and signature lines
  • Built-in concrete cubic yard calculator
  • Project templates for common residential jobs
  • Admin panel to manage and update prices

PlanRight — Project Timeline Planner
HTML CSS JavaScript html2canvas jsPDF

Overview

A construction project scheduling tool built for contractors. Enter a project's build phases (permits, foundation, framing, roofing, etc.) with a duration for each, and it automatically calculates a sequential timeline — each phase starts the day after the previous one ends.

Key Features

  • Dashboard with key stats: start date, total duration, phase count, and projected finish date
  • Visual color-coded Gantt chart of the full project timeline
  • Progress view with a completion ring, current phase, and days remaining based on today's date
  • Phase-by-phase report table
  • One-click branded PDF export with project and client info, Gantt chart, and summary table — ready to hand to a client
